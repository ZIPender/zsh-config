# Zsh Terminal Setup

My Arch Linux terminal configuration.

Dark, minimal, purple-themed, and focused on useful CLI tooling without a large shell framework.

## Preview

The setup uses:

- Zsh
- Starship
- Konsole
- JetBrains Mono Nerd Font
- fzf
- zoxide
- eza
- bat
- fd
- ripgrep
- git-delta
- lazygit
- yazi
- btop
- fastfetch
- zsh-autosuggestions
- zsh-syntax-highlighting
- zsh-completions

Designed for **Arch Linux**.
